# OpenDMA

OpenDMA is an open direct memory access (DMA) core between AXI4 memory and AXI4-Stream peripherals that is based on
the Open Logic VHDL Library. Its register map, descriptor format and programming sequences are those of the AMD AXI
DMA (product guide PG021, version 7.1), so that software written for that core, including its bare-metal and Linux
drivers, runs on OpenDMA unchanged. The core is vendor-independent VHDL-2008, and all buffers use the fault-tolerant
entities of [Open Logic](https://github.com/open-logic/open-logic) (SECDED ECC).

AMD and AXI DMA are named only to state the compatibility of the register interface. OpenDMA is an independent
implementation written from the published product guide; it contains no code, text or figures of AMD.

## Status

**In development.** Direct Register Mode (phase a) and Scatter/Gather Mode (phase b, with packets of several
buffers and keyhole transfers) are implemented and verified in simulation with GHDL; the QuestaSim runs with code
coverage are open. The control and status streams follow in phase c. The [roadmap](docs/roadmap.md) lists the
development phases and the state of every module.

## Repository structure

```text

|-- docs/             Top-level documentation
|-- hdl/<module>/     One folder per module: src/, tb/, docs/
|-- tb/               Verification components shared by the testbenches
|-- lint/             VSG configuration (Open Logic rules), synthesizability check
|-- tools/            Compliance matrix and register map generators
|   `-- docs/         Documentation website (MkDocs)

```

## Running the tests

Prerequisites: Python 3, [GHDL](https://github.com/ghdl/ghdl) on the `PATH` and the Python packages of
`requirements.txt`.

```shell
git submodule update --init
python -m pip install -r requirements.txt
python run.py -p 8              # full regression with GHDL, 8 parallel simulations
python run.py "*odma_<module>*" # one module
python run.py --questa <test>   # QuestaSim
```

`run.py` compiles Open Logic into the VHDL library `olo`, the required UVVM components into their own libraries and
all OpenDMA sources into the library `opendma`. `ODMA_GHDL_SIM_FLAGS` passes extra flags to the GHDL simulation,
for example `--vcd=wave.vcd` for a waveform.

Checks besides the regression:

```shell
python lint/lint.py                 # VSG, no errors and no warnings
python tools/compliance.py --check  # every item of the published interface traced to a test case
python tools/regmap.py --check      # generated register map files match hdl/odma_registers/regs/odma_regs.yml
python run.py --compile-order       # compile_order.txt; the CI fails when the file changes
python -m mkdocs build -f tools/docs/mkdocs.yml  # documentation website, fails on broken links
```
