# OpenDMA: Compliance Matrix

Generated by `python tools/compliance.py` from the requirement traceability matrix of the
[architecture](architecture.md) (section 10), the requirements of the module specifications and the test cases
of the module verification plans. `python tools/compliance.py --check` fails when an item or a requirement has
no test case, or when a test case of a plan is not run by a testbench.

## 1. Items of the published interface

An item is listed with every requirement that traces to it and with the test cases that verify these
requirements. An item is verified when every requirement that traces to it is verified by a test case, and
partly verified while the other requirements belong to modules without a testbench yet, to a later
development phase (for example the Scatter/Gather function of a status bit that is verified in Direct
Register Mode) or wait for a change of Open Logic. An item is planned while its development phase is open,
none of its owner modules has a testbench yet or all its requirements are planned. The interpretations of
the published interface are listed in section 6 of the architecture and in the module specifications.

## 3. Interpretations of the published interface

Where \[PG021\] is open or inconsistent, OpenDMA behaves as listed below. Each row names the PG021
section it interprets and the behaviour that software written for PG021 observes, and the documents that
state it (the architecture, section 6, and the module specifications, section 4).

| ID | Item | PG021 | OpenDMA | Documents |
| --- | --- | --- | --- | --- |
| I1 | `MM2S_DMACR.Keyhole`, `S2MM_DMACR.Keyhole` in DR mode | Table 6 calls the MM2S bit non-functional in DR mode, Table 16 does not restrict the S2MM bit | As published (P4): the MM2S bit is stored but has no function in DR mode; the S2MM bit works in both modes, the MM2S bit in SG mode (phase b) | architecture |
| I2 | `MM2S_DMACR.IOC_IrqEn` | Table 6 lists bit 1, Figure 3 and Table 16 bit 12 | Bit 12 in both channels | architecture, odma_registers |
| I3 | `DMACR.RS` after an error | The error clears `RS`; restarting without a reset is not described | `RS` = 1 has no effect while an error flag is set (D7) | architecture, odma_registers |
