# odma_registers: Register Map

Generated by `tools/regmap.py` from `hdl/odma_registers/regs/odma_regs.yml`, do not edit.
The same description generates the VHDL package `odma_regs_pkg` and the C header `sw/odma_regs.h`.

Byte addresses of 32-bit registers on the AXI4-Lite port (10-bit address); unused addresses and bits read as zero.
The registers below 0x100 are those of the AXI DMA product guide PG021 in Direct Register Mode, with the
names of the product guide; the window from 0x100 holds the extension registers of OpenDMA.
`EXT_ID` reads 0x4F444D41.

| Access | Meaning |
| --- | --- |
| RO | Read only |
| RW | Read and write |
| W1 | Write one: command; reads as zero |
| W1C | Sticky flag; write one to clear |
| WO | Write only; reads as zero |
| RC | Read only; any write to the register clears it |

## FT buffers

Index of a buffer in `ECC_COUNT`, `ECC_INJECT.Buffer` and the ECC ports; indices without a buffer count nothing.

| Index | Buffer |
| --- | --- |
| 0 | MM2S read data buffer (olo_ft_axi_master_full) |
| 1 | S2MM data buffer (olo_ft_fifo_sync) |
| 2 | S2MM chunk buffer (olo_ft_fifo_sync) |
| 3 | S2MM write data buffer (olo_ft_axi_master_full) |
| 4 | MM2S transfer buffer (olo_ft_fifo_sync) |
| 5 | MM2S response buffer (olo_ft_fifo_sync) |
